# 《吞噬进化Games》(Devour Evolution Games) - 抖音 3D 休闲竞技小游戏

> **一句话玩法**：控制一个初始微小的黑洞，在现代卡通城市中自由穿梭，从易拉罐、路障、快递纸箱一路吞噬进化至轿车、货车、公交车直至摩天大厦与历史钟楼！支持【紧张刺激的 3 分钟 AI 竞技对战】与【纯净解压的零 AI 独占无尽模式】，并配备完整的黑洞皮肤衣橱、天赋强化研究所、荣誉成就殿堂、雷达小地图与掉落道具！

---

## 🎮 完整游戏系统与核心玩法

### 1. 经典双模式自由选择
- **⚔️ 竞技对战模式 (Battle Mode)**：
  - 限时 **3 分钟** 排位赛，右上角实时动态积分榜。
  - **6 位个性化 AI 黑洞对手**（凶猛猎手、农夫发育、战术大师、逃逸专家、街区霸主、路痴新手）。
  - 支持黑洞大吞小猎杀对决，击溃对手引发大爆炸特效，被吞后在安全区降级复活。
- **♾️ 纯净无尽模式 (Endless Mode)**：
  - **严格去除所有 AI 对手（地图上 0 个 AI）**，没有任何竞争骚扰与被吃风险。
  - 不限时间，右上角实时统计**全城清空百分比（如 `清空进度: 45% | 吞噬统计: 140 / 312`）**，纯享将整座城市连根拔起的极致解压体验。

### 2. 抖音手游原生操控体系
- **左下角常驻霓虹发光虚拟摇杆**：
  - 动态触屏跟随与回弹，灵敏转向不遮挡视线。
  - 向下兼容 PC 键盘 `W` / `A` / `S` / `D` 与鼠标按住拖拽。
- **局内随时暂停 (⏸)**：
  - 支持随时暂停对局，调节音效/音乐开关，或选择重新开始与返回主页。

### 3. 局外成长与个性化经济生态
- **🪙 金币积累与战报结算**：
  - 每局游戏根据吞噬得分、吞噬数量、击败对手数与排名结算丰厚金币。
  - 战绩持久化保存于本地，离线不丢档。
- **🎨 个性黑洞皮肤衣橱 (Skins)**：
  - **未来深蓝 (Neon Cyan)**：经典赛博科技，视界边缘泛着霓虹青辉 (默认)。
  - **地狱熔岩 (Inferno Crimson)**：灼热星核熔浆，所过之处万物焚为灰烬。
  - **虚空暗紫 (Void Violet)**：异次元裂隙能量，折叠时空的暗夜霸主。
  - **日耀炽金 (Solar Gold)**：恒星耀斑冠冕，纯金粒子环绕的霸道威仪。
  - **幻彩极光 (Chroma Aurora)**：梦幻霓虹流光，在不同光谱间永恒流转。
- **🧪 黑洞能力研究所 (Talent Upgrades)**：
  - **引力场强化**：每级提升 +8% 基础吸引范围。
  - **超维曲速引擎**：每级提升 +6% 基础移动速度。
  - **黑洞消化吸收率**：每级提升 +10% 经验与积分收益。
- **🏆 荣誉成就殿堂 (Achievements)**：
  - 9 项精心设计的挑战徽章（如“初窥深渊”、“超维风暴”、“全城清道夫”、“天际线瓦解”等），达成即时触发顶部金色横幅 Toast 并领赏大笔金币！

### 4. 局内动态道具与战场感知
- **掉落神秘能量晶石**：
  - ⚡ **极速冲刺**：6 秒内移速飙升 50%。
  - 🧲 **超维强磁**：7 秒内吸力范围扩大 75%。
  - 💎 **双倍能量**：8 秒内吞噬经验与得分翻倍。
  - ⏰ **时间沙漏**：立即延长比赛时间 +15 秒。
- **右上角微型雷达小地图 (Radar Mini-Map)**：
  - 动态显示城区十字坐标、自身方位脉冲、掉落道具菱形点、AI 对手位置与危险天敌红点。

### 5. 9 级体型成长与物理反馈体系
1. **Lv.1 初生微洞**：易拉罐、快递纸箱、路障锥。
2. **Lv.2 街道游荡者**：市政垃圾桶、消防栓、花盆、邮筒。
3. **Lv.3 街区吞噬者**：公园长椅、路灯、小树、自动售货机、交通信号灯。
4. **Lv.4 暴食漩涡**：摩托车、热狗餐车、景观树。
5. **Lv.5 载具收割者**：家用小轿车、出租车、SUV。
6. **Lv.6 重装粉碎机**：厢式物流货车、参天古松。
7. **Lv.7 巨物捕食者**：城市大型公交车、喷泉广场。
8. **Lv.8 城镇瓦解者**：独栋住宅、便利店。
9. **Lv.9 万物寂灭**：摩天商业写字楼、时代金融中心、市政复古钟楼！

## 🚀 本地运行与体验

1. **双击启动脚本**：
   直接双击运行根目录下的 `start_game.cmd`。
2. **浏览器直接访问**：
   在任何现代浏览器中打开：
   👉 `http://localhost:8080/index.html`

## 🛠️ 项目架构一览
```
devour-evolution/
├── index.html                   # 游戏主页与所有 HUD / 模态框 DOM 结构
├── style.css                    # 玻璃拟态手游视觉体系与动画样式
├── main.js                      # 模块入口引导启动
├── start_game.cmd               # Windows 一键启动脚本
├── game.json / project.config   # 抖音小游戏原生适配配置
├── libs/                        # 本地内置 Three.js 引擎库
└── src/
    ├── config.js                # 游戏配置、等级表、皮肤、天赋、道具与调色板
    ├── GameManager.js           # 游戏总控中心 (主循环、对局生命周期、碰撞与结算)
    ├── audio/
    │   └── AudioManager.js      # 纯 Web Audio 原生音效与合成器 BGM 系统
    ├── entities/
    │   ├── BlackHole.js         # 3D Stencil 挖洞黑洞实体 (吸积盘、粒子、皮肤、天赋)
    │   ├── PlayerController.js  # 手游发光虚拟摇杆与震屏触控控制器
    │   └── AIController.js      # 6 位个性化 AI 分时决策状态机
    ├── models/
    │   └── ModelFactory.js      # 9 大等级及城市构件低面多边形 3D 模型生成工坊
    ├── services/
    │   ├── StorageManager.js    # 本地存档与金币、皮肤、天赋持久化服务
    │   └── AchievementManager.js# 成就系统判定与奖励分发服务
    ├── ui/
    │   └── UIManager.js         # 模式选择、皮肤衣橱、研究所、雷达、暂停、战报面板
    ├── vfx/
    │   └── ParticleSystem.js    # 吞噬微粒、升级光环、消灭爆炸粒子系统
    └── world/
        ├── CityBuilder.js       # 160m 现代卡通城市场景与路网构建器
        ├── ConsumableManager.js # 空间网格物体引力计算与下沉动画管理器
        └── PowerUpManager.js    # 3D 浮空动态掉落道具刷新与收集管理器
```
